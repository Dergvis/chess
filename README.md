# ♔ Шахматы для Гоши

Детская шахматная PWA/web-игра с весёлыми персонажами и классическими правилами.

## 🎮 Описание

**Шахматы для Гоши** — это адаптивная шахматная игра для детей 5-10 лет, которая работает на:
- мобильных устройствах
- планшетах
- ноутбуках
- десктопах

### Ключевые особенности MVP:
- ✅ **Классические шахматные правила** — не меняются, только подача
- ✅ **Игра против ИИ** с 3 уровнями сложности
- ✅ **2 оригинальных стиля фигур**:
  - 🧊 **Кубики** — block-inspired стиль
  - 🧱 **Лего-человечки** — brick/minifigure стиль
- ✅ **6 персонажей-соперников** с характером и эмоциями
- ✅ **10 комедийных анимаций при взятии**:
  - Катапульта
  - Игрушечная пушка
  - Пружина
  - Мини-эвакуатор
  - Люк
  - Свисток и помощники
  - Вентилятор
  - Банановая кожура
  - Воздушные шарики
  - Телепорт
- ✅ **Эмоциональные реакции** на шах/мат/победу/поражение
- ✅ **PWA-оболочка** (работает офлайн)
- ✅ **Адаптивный интерфейс** (mobile/tablet/desktop)
- ✅ **Улучшенная подсветка ходов**:
  - Зелёные маркеры для обычных ходов
  - Красные кольца для взятий
  - Пульсация для опасных ходов
  - ⚠️ предупреждение о шахе

## 🚀 Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```

Сервер запустится на `http://localhost:5173`

### Доступ по сети
Для доступа с других устройств используйте IP вашего компьютера:
- `http://192.168.1.16:5173` (локальная сеть)
- Или ваш внешний IP: найдите через `ipconfig`

### Сборка для продакшена
```bash
npm run build
```

### Предпросмотр продакшен-сборки
```bash
npm run preview
```

## 🏗 Архитектура

### Слои приложения (по ТЗ)

1. **Chess Core** (`entities/chess/ChessCore.ts`)
   - Управление шахматной логикой
   - Генерация легальных ходов
   - Проверка шаха/мата/пата
   - Рокировка, превращение пешки, en passant
   - **Полностью независим от UI**

2. **AI Adapter** (`features/game/AIAdapter.ts`)
   - Интеграция с ИИ
   - 3 уровня сложности (easy/medium/hard)
   - Искусственные ослабления для разных уровней
   - Вероятность ошибок (blunder probability)

3. **Animation Event System** (`entities/animation/AnimationEventSystem.ts`)
   - Очередь событий анимаций
   - 3 режима интенсивности (full/short/minimal)
   - Приоритизация событий
   - Skippable behavior

4. **Game Orchestrator** (`app/App.tsx`)
   - Связывает все модули
   - Управляет состояниями игры
   - Координирует ходы игрока и ИИ

5. **Presentation Layer** (`features/*/`)
   - Рендеринг UI
   - Адаптивность
   - Обработка ввода
   - Анимации

## 🎯 Игровые режимы

### Уровни сложности

| Уровень | Глубина | Случайность | Blunder % | Описание |
|---------|---------|-------------|-----------|----------|
| Лёгкий | 1 | 40% | 30% | Для начинающих |
| Средний | 3 | 20% | 10% | Для опытных |
| Сложный | 5 | 5% | 2% | Для экспертов |

1. 🐻 **Миша-Шахматист** (лёгкий) — дружелюбный медвежонок

3. 🦉 **Сова-Мудрюга** (средний) — мудрая и спокойная
4. 🦁 **Лев-Чемпион** (средний) — сильный и уверенный
5. 🐉 **Дракоша** (сложный) — маленькие амбиции
6. 🤖 **Робот-Считайка** (сложный) — логический

### Стили фигур

1. **Кубики** (block-inspired)

   - Модульные фигурки
   - Пластиковый блеск
   - Ассоциация с конструктором

## 🎨 Анимации взятия

### Принцип работы
Когда одна фигура "съедает" другую:
1. Фигура A делает ход на клетку фигуры B
2. Запускается короткая сценка (1-2 секунды)
3. B комично выбывает (улетает, уезжает, исчезает)
4. A занимает клетку по шахматным правилам

### Типы анимаций (10 штук)

| Анимация | Длительность (full) | Стиль |
|----------|---------------------|-------|
| Катапульта | 1500ms | cartoon |
| Пушка | 1200ms | playful |
| Пружина | 1000ms | cartoon |
| Эвакуатор | 1800ms | cartoon |
| Люк | 1000ms | playful |
| Свисток | 1400ms | cartoon |
| Вентилятор | 1200ms | playful |
| Банан | 1300ms | cartoon |
| Шарики | 1600ms | magical |
| Телепорт | 1000ms | tech |

### Режимы интенсивности
- **Full** — полная анимация со всеми эффектами
- **Short** — укороченная версия (50%)
- **Minimal** — минимальный feedback (20%)

## 🎮 Как играть

### Первый запуск
1. Пройдите короткий онбординг:
   - Введите имя
   - Выберите опыт игры
   - Выберите стиль фигур
2. Посмотрите демо анимации

### Начало игры
1. Нажмите **"Играть"** в главном меню
2. Выберите:
   - Соперника (карточка с аватаром)
   - Уровень сложности
   - Стиль фигур
   - Цвет (белые/чёрные)
3. Нажмите **"Начать игру!"**

### Во время игры
- **Клик** на фигуру → выбор
- **Зелёный кружок** → можно пойти
- **Красное кольцо** → можно съесть
- **⚠️ на короле** → шах!
- Жёлтая подсветка → последний ход

### После партии
- Экран результата с эмоцией соперника
- Кнопки "Сыграть ещё" / "В меню"

## 📝 Расширение (по ТЗ)

### Добавление нового персонажа

Откройте `src/entities/character/characters.ts`:

```typescript
{
  id: 'unicorn',
  name: 'Единорог',
  avatar: '🦄',
  theme: 'fantasy',
  difficultyPreset: 'medium',
  description: 'Волшебный единорог из сказочного леса',
  reactions: {
    gameStart: ['Привет! Готов к волшебной партии?'],
    goodMove: ['Магически!'],
    losePiece: ['Ой, моя фигурка!'],
    check: ['Шах! Волшебная атака!'],
    checkmate: ['Волшебство победило!'],
    win: ['Ура! Магия сильнее!'],
    lose: ['Твоя магия сильнее моей!'],
  },
  soundPack: 'magical',
  preferredAnimationFlavor: 'magical',
}
```

### Добавление новой анимации взятия

Откройте `src/entities/animation/captureAnimations.ts`:

```typescript
{
  id: 'rocket',
  name: 'Ракета',
  description: 'Фигура улетает на ракете',
  eventType: 'MOVE_CAPTURE',
  duration: { full: 2000, short: 1000, minimal: 400 },
  skippable: true,
  flavor: 'tech',
}
```

Затем добавьте CSS-анимацию в `CaptureAnimation.css`.

### Добавление нового стиля фигур

Откройте `src/entities/piece-skins/pieceSkins.ts` и добавьте новый скин.
